# Urban-Trade

A modern full-stack MERN application built for urban marketplace and trading services. The platform allows users to explore products/services, manage accounts, and interact through a clean and responsive user interface.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/priyankverma7/Urban-Trade.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd Urban-Trade
```

## 3️⃣ Install Dependencies

### Frontend

```bash
cd client
npm install
```
## Start Frontend

```bash
cd client
npm run dev
```
